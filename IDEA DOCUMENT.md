&#x20;     **Hospital Bed Availability Board**













**1. Project Title**



**Hospital Bed Availability Board**





**---**



**2. Problem Statement**



**During emergencies, patients and their families often struggle to find hospitals with available beds or ICU facilities. Hospital staff also face difficulties in updating and sharing bed availability efficiently. This leads to delays in treatment and poor resource management.**





**---**



**3. Proposed Solution**



**The Hospital Bed Availability Board is a web-based application that displays real-time availability of hospital beds. It allows hospitals to update bed status while enabling the public to check available beds instantly. The system provides quick access to bed information, helping reduce delays during emergencies.**





**---**



**4. Objectives**



**Display real-time hospital bed availability.**



**Allow hospitals to update bed status.**



**Help patients find available ICU and ward beds.**



**Improve hospital resource management.**



**Ensure secure access using role-based permissions.**







**---**



**5. Features**



&#x20; **\*Bed Status CRUD**



**Add new beds**



**Update bed availability**



**Delete bed records**



**View current status**





&#x20; **\*ICU/Ward Filters**



**Filter beds by:**



**ICU**



**General Ward**



**Emergency Ward**







&#x20;**\*Public Map**



**Display hospital locations on a map.**



**Allow users to identify nearby hospitals.**





&#x20;**\*Update API**



**Enable hospitals to update bed availability through an API.**





&#x20;**\*Audit Log**



**Record every update made to bed status.**



**Store update time and user details.**





&#x20;**\*Role-Based Access**



**Admin: Manage bed data.**



**Hospital Staff: Update bed availability.**



**Public User: View bed availability only.**







**---**



**6. Target Users**



**Hospitals**



**Patients**



**Ambulance Services**



**Government Health Departments**

**7. Technology Stack**



**Component	Technology**



**Frontend	HTML, CSS, JavaScript**

**Backend	Python (Flask)**

**Database	SQLite / MySQL**

**API	Flask REST API**

**Map	Google Maps**







**---**



**8. Workflow**



**1. Hospital staff logs in.**





**2. Updates bed availability.**





**3. Data is stored in the database.**





**4. Public users access the website.**





**5. Users filter ICU or General Ward beds.**





**6. System displays available beds and hospital location.**





**7. Every update is recorded in the audit log.**
